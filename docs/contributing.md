# Contributing Guidelines — RailOptix-AI

---

## How to Contribute

1. **Fork & Clone**: Fork the repository and clone to your local environment.
2. **Branching**: Create a feature branch following the naming pattern: `feature/description` or `fix/description`.
3. **Build Check**: Ensure both server and client build cleanly prior to committing:
   ```bash
   npm --prefix server run build
   npm --prefix client run build
   ```
4. **Pull Request**: Open a Pull Request detailing changes, tested scenarios, and screenshot verification for UI modifications.
